# DCS World Screenshots

Place your DCS World screenshots in this directory. The homepage and features
page reference the following files:

| File | Used in | Description |
|------|---------|-------------|
| `dcs-tower.jpg` | Homepage | Tower view with AI traffic on final |
| `dcs-cockpit.jpg` | Homepage | Cockpit view during taxi |
| `dcs-approach.jpg` | Homepage | Approach view with ILS intercept |
| `dcs-multiplayer.jpg` | Homepage | Multiplayer session with ATC |
| `dcs-tower-2.jpg` | Features page | Additional tower screenshot |
| `dcs-ground.jpg` | Features page | Ground operations screenshot |

## Recommended specs

- Format: JPG or WebP
- Resolution: 1920x1080 or higher (16:9 aspect ratio)
- File size: under 500 KB per image (use `cwebp` or `jpegoptim` to compress)

## How to capture DCS World screenshots

1. Launch DCS World with DCS AI ATC running
2. Press `Ctrl` + `Pause` (or your custom screenshot key) during a mission
3. Screenshots are saved in `DCS World\Screenshots\`
4. Rename and copy them here
